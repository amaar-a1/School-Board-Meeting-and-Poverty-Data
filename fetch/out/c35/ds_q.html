Dataset

Dataset Pendidikan berisi kumpulan data induk yang sudah dikelompokkan berdasarkan topik tertentu. Dataset ditampilkan dalam bentuk tabel dan dapat diunduh dalam format .XLSX, .CSV untuk analisa lebih lanjut.

Informasi lebih lanjut terkait Dataset dapat diakses melalui halaman Pusat Informasi.

TOPIK YANG TERSEDIA

Prioritas

Laman Dataset Prioritas berisi kumpulan data strategis yang ditetapkan dalam forum Satu Data Indonesia sebagai Data Prioritas Kementerian Pendidikan Dasar dan Menengah. Dataset ditampilkan dalam bentuk tabel dan dapat diunduh dalam format .XLSX, .CSV untuk analisa lebih lanjut.

Statistik

Laman Dataset Statistik berisi kumpulan data yang sudah dikelompokkan berdasarkan topik dan cutoff tertentu. Dataset ditampilkan dalam bentuk tabel dan dapat diunduh dalam format .XLSX, .CSV, .JSON, .PDF untuk analisa lebih lanjut.
